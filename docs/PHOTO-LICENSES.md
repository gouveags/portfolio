## Adaptations and reuse

The source JPEGs were resized with Lanczos resampling and encoded as WebP. Desktop versions preserve the complete source frame. Mobile versions are cropped to 900 × 1948 pixels. The site may apply CSS grayscale, darkening, viewport cropping, and optional pan/zoom/crossfade motion. The effects animate still photographs; they are not video footage. No generative editing or compositing was used.

Each photograph adaptation, including its cropped and monochrome presentation, is offered under the exact same CC BY-SA license as its source, linked individually below. Keep the photographer credit, original title, source, license, and adaptation notice when redistributing. The photo licenses apply to the listed photographs and their adaptations; this notice does not assign a license to other site material.

## Framing and loading

- Default desktop: Porsche. `desktopPosition: "50% 50%"` matches the v4 design board’s centered crop at 16:10. The desktop asset itself remains uncropped.
- Default mobile: Theatro. Its 900 × 1948 crop uses the same centered composition as the v4 mobile board.
- Porsche mobile crop is right-weighted (75% source alignment) to retain the car; Ferrari and Eau Rouge use 60% source alignment. These are pre-cropped, so all `mobilePosition` values are `50% 50%` to avoid an unintended second art-direction shift.
- Image order in `src/data/wallpapers.json`: Porsche, Theatro, Ferrari, Eau Rouge.
- Use the mobile source in portrait mobile layouts and the desktop source on desktop. Serve only the active wallpaper and, when needed, the next candidate rather than downloading every variant.
- Respect reduced motion with a stationary selected photograph. Stop optional rotation while the document is hidden.
